# rambodparsi.github.io

Hi! This is the source of my personal website, live at **[rambodparsi.github.io](https://rambodparsi.github.io/)**.

I'm Rambod Ghandiparsi, a PhD student in Computer Science at UT San Antonio. I work on software engineering, requirements engineering, and AI-assisted software development. The site is a quick way to find my research, publications, and CV.

## What's inside

It's intentionally simple: one HTML page, no frameworks, no build step.

- `index.html`: the whole website
- `profile.jpg`: my profile photo
- `CV.pdf`: my latest CV

## Updating it

To swap in a new CV or photo, upload a file with the same name (`CV.pdf` or `profile.jpg`) to the `main` branch. GitHub Pages republishes the site within a minute or two.
